# スライダー

世の中の仕組みを、文章で読む前に数字を触って理解する教育アプリです。

金利、給料、為替、通勤、電気代。スライダーを動かすと、結果の数字とグラフがすぐに変わります。時代ボタンで、過去の数字といまを比べることもできます。

## 公開

- アプリ: https://dai-robot.github.io/slider/
- リポジトリ: https://github.com/dai-robot/slider

## ローカル

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開きます。
